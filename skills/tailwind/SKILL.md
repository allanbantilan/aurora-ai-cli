# Tailwind

- Prefer utility classes in templates and mobile-first responsive prefixes.
- Use the configured palette and design tokens; avoid arbitrary values unless truly one-off.
- Respect existing dark-mode and component conventions.
- Keep interactive components accessible with semantic HTML and keyboard behavior.
- Use custom CSS only when utilities cannot express the requirement cleanly.
